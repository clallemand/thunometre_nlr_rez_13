# thunometre_nlr_rez_13

Outil de prise en compte des inégalités de ressources et de classe sociale pour la participation financière.

## Utilisation

L'application est entièrement statique : les réponses et le résultat ne quittent jamais le navigateur.

```sh
npm start
```

Ouvrir ensuite l'adresse indiquée dans le terminal. Le fichier `index.html` peut aussi être servi par n'importe quel serveur HTTP statique.

## Tests

```sh
npm test
```
